In one line

Point your iPhone at any QR code and it blooms into a portal; battle the creature that steps out, then catch it by reading its scattered code.

Description

Codekin turns the QR codes all around us into portals. Point an iPhone at any code (a restaurant menu, a concert poster, the Wi-Fi sign at a café) and the code's own squares rise off the paper as glowing columns while a Codekin, a creature made of living data, steps out onto the real surface.

Battles are turn-based and play out right where the code is printed. To catch a wild Codekin, players weaken it and then decode it: its code fragments scatter around the room, and they move the phone to read each one before time runs out.

What a code points to decides what lives behind it, so menus, Wi-Fi signs, parks, shops and pay codes each draw different Codekin, and every Codekin carries the signature of the code it came from, so no two look quite alike. There are 131 to find, eight elements, legends that move from code to code, and mythics that only answer to secrets. Friends standing side by side can battle on one shared code or trade face to face.

Features

  • Any QR code in the world is a level, and what it points to decides what lives inside.
  • 131 Codekin across eight elements, each individual shaped by its own code.
  • AR battles on the real table or wall, with a skill-based catch.
  • Eighteen habitats, daily goals, streaks, trainer ranks, weekly featured codes and monthly elements.
  • Local battles and trades with a friend nearby.
  • No accounts, ads or tracking. Works on iPhones with or without LiDAR.
