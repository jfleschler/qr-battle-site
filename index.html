How it works

Three steps, any code, anywhere

  1. 1

    Scan

    Hold your phone up to any QR code. The corners lock on and the code blooms into a portal right where it's printed.

  2. 2

    Battle

    The Codekin inside steps out onto the real surface. Pick moves with an eye on matchups: blaze, tide, grove, spark, stone, gale, shade and prism.

  3. 3

    Decode

    Weaken it, then catch it: its code fragments scatter around you, and you move your phone to read each one before time runs out.

The Codekin

131 creatures made of living data

Every code hides its own Codekin, and each one carries the signature of the code it came from, so no two look quite alike. Legends move from code to code, and a few only answer to secrets.

    Habitats

    Different codes draw different Codekin

    What a code points to decides what lives behind it. Menus run hot, waterside codes run wet, and pay codes hide rare finds. Track down all eighteen.

      One of a kind

      Show off every catch

      Each Codekin's look comes from the code it rose out of. Share a card of your newest catch, with its code mark and the kind of place it was hiding, never what the code says.

      Face to face

      Battle and trade with a friend

      Stand next to each other, scan the same code, and fight or swap Codekin on one shared stage.

      Every day

      Goals, streaks and rank

      Three new goals each day, a streak bonus for coming back, and a trainer rank that draws out stronger Codekin as you grow.

      Camera images are processed on your iPhone and never leave it. Your save is backed up to your own iCloud.
